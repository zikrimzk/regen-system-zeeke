- The gallery uses real template captures, with 320/640 px responsive WebP sources, fixed dimensions, asynchronous decoding and lazy loading. All ten 320 px previews total 121,428 bytes; the complete 640 px collection totals 391,980 bytes. Individual images load as needed. Full readable previews still open on request.
- The walkthrough resume and letter wait until visible. A hidden cover letter no longer loads during first paint. Edited sample details are retained when the document appears.
- The original transparent logo is retained. Lossless WebP variants serve different pixel densities; PNG remains the fallback. Display-size app marks replace unnecessarily large illustration icons.
- The UI prefers native platform fonts. The public page no longer forces an Inter preload on every device. The four existing document fonts are losslessly compressed with FontTools; glyph widths, glyph order and character coverage are checked. PDF generation continues using the original TTF files.
- The hero button now exposes “View full document” to assistive technology. Gallery choices announce “Choose [design]” or “Selected [design]” to match their visible state. Decorative arrows are hidden from the accessibility tree.
- The public page uses a dedicated generated stylesheet rather than loading private editor skins. `composer check` rebuilds it from maintained CSS sources.
- Tablet overflow from the decorative hero scene is clipped at the main page boundary. Public buttons have a minimum layout height of 44 px. Auth inputs use 16 px text at all breakpoints.
- Mobile document sheets fill the available width; the browser's default dialog maximum no longer compresses them. Dates stack below entry titles in readable phone previews. The close header stays available while scrolling.

## Cache behavior

- Release HTML and responsive logo sources have content-versioned asset URLs. Apache gives those static assets a one-year immutable cache lifetime. Unversioned image assets have a seven-day lifetime and normal validators.
- Gzip remains enabled for CSS, JavaScript, HTML and JSON. An isolated Apache 2.4 server verified actual compression, WebP MIME types, immutable asset headers and single `no-cache` headers for the service worker/manifest.
- The release worker warms the same versioned CSS/JS/image URLs used by its HTML. Concurrent warm-up work is coalesced; repeated messages to the same worker with the same privacy choice are skipped.
- Optional public offline storage remains controlled by the user's choices. APIs, authentication, workspaces, downloaded documents and uploaded photos remain excluded. Rejecting optional storage removes ReGen public Cache Storage. HTTP caching of static assets is separate from storing private workspace pages.

## Upload and repeat the audit

1. Back up the deployment and preserve its `.env`, uploads and storage. Upload the contents of `release/regen-php.zip` using the existing DirectAdmin deployment process. This update adds no database migration; older installations still need migration 010 as documented in `UAT_UPDATE.md`.
2. Confirm the new public stylesheet and worker version are live. The service worker offers an optional reload without discarding a draft automatically. Do not clear private account/session data to update static assets.
3. Rerun [SEO Review Tools](https://www.seoreviewtools.com/pwa-testing-tool/) and retain the complete per-audit report. Also test a cold mobile visit and an installed launch on an actual Android device and iPhone/iPad. A new score can be reported only from a new deployed run.

Development asset regeneration: `php scripts/build-site-css.php`; `node scripts/optimize-site-images.mjs <capture-directory>` with Sharp; `python scripts/optimize-document-fonts.py` with FontTools and Brotli. These tools are used locally. The PHP hosting server needs none of the Node/Python build dependencies.
