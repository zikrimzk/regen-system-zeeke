# Kerjayaku Worlds · Cinematic Malaysian Career Journey

This is the proposed Phase 02J.3 visual direction. The first browser evaluation covers the opening, Resume Studio and premium toll.

| Rule | Production direction |
| --- | --- |
| Camera | Slightly elevated three-quarter architectural view with a 45–55 mm equivalent. The skyline keeps near-upright verticals, and roads and interiors recede into their scenes. |
| Light | Warm morning key from upper left, cool open-sky fill and soft contact shadows. Tone down highlights around text and reserve bright lamps for useful landmarks. |
| Materials | Stainless steel and glass for KLCC, warm stone and matte asphalt outside, oiled timber and paper in the writing studio. Red and amber accents orient the eye. |
| Ground | Continuous ground inside each environment. Fade the photograph-like artwork into the page’s road shoulders at the edges. No visible model bases. |
| Character scale | One established Mochi silhouette. Start with a readable face in the hero, scale gradually into walking size, and keep the contact shadow centred on the road. Separate character art from environments. |
| Road scale | The existing travel path is a compressed pedestrian connector on the page. Its painted continuation inside each image follows that image’s perspective. Curbs, shoulders and lane dashes use the same warm greys. |
| Detail | Put detail at the destination and use quiet side margins for the route. The hero opens on the towers and park road, with the two pilot checkpoints introducing different destinations. |
| Motion | The scroll controller still owns position and reverse progress. Art stays in stable layouts. Reduced motion keeps the hero character as a static layer. |
| Files | Asset masters use scene names under `art/kerjayaku-worlds/`. Public exports use scene, crop and pixel width in `public/img/worlds/`. Browser evidence goes under this document’s `evidence/` directory. |

Mobile art uses designed crops that preserve the main silhouette or focal detail, plus a mobile road join. The original headlines, links, navigation and page hierarchy supply the context for the art.
