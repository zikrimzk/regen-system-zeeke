# Mobile and PWA QA

The candidate dock uses visible labels, a five-destination maximum, safe-area offsets and a native More dialog. Editors observe `visualViewport` through the existing module. Cover Letter Studio joins the focus-reveal behavior. While the software-keyboard heuristic is active, the dock hides and editing retains the remaining usable height.

The service worker and manifest use the existing infrastructure. The new local preferences contain booleans for panel layout. Neither Studio writes private drafts into browser storage. A browser warning remains available if a candidate leaves with unsaved edits. A disconnected browser keeps typed edits in the current page and reconnects through the existing save or session flow.

The existing manifest still uses the ReGen install label. The candidate shell uses the Kerjayaku wordmark. Install identity, icon migration and actual native keyboard behavior remain device-review items.

See [functional regression](functional-regression.md) for the width matrix, native limitations and manual device checklist.
