# Mochi and contextual AI

Both Studio headers offer the existing Mochi panel when the current availability state exposes it. The shared launcher keeps the companion out of document controls. The panel still uses its existing workspace context, explicit field sharing, saved-resume option where permitted and existing reduced-motion behavior. Candidate typing does not trigger new provider activity from this phase.

Resume Assist Me and Refine Me continue to attach to supported writing fields via `assist-me.js` and `ai-enhance.js`. Cover Letter Studio retains its explicit generation request and separate review, apply and discard actions. Admin feature switches, package limits, privacy filtering and usage settlement continue in the existing PHP action and service layers. No provider prompt, model, key, setting or credit rule was changed.

Browser tests can substitute a fixed cover-letter suggestion and AI status response in the synthetic session. That tests the real application controls without contacting a model.
