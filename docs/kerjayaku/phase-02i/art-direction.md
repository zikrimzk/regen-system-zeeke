# Art direction

The landing presents one miniature world in warm paper, charcoal, muted terracotta, and brass. The original vector artwork in `public/img/kerjayaku-world.svg` uses shared silhouettes, windows, vegetation, shadows and perspective. The existing green Mochi sprite is the exception to the neutral and red interface palette. The path starts at the hero diorama and links the rest of the scenes.

The Kuala Lumpur illustration uses a joined twin-tower silhouette, the faceted outline and offset spire of Merdeka 118, and a separate stepped office tower. The later bridge scene uses two cable-stayed pylons inspired by Penang Bridge. The illustration is symbolic and built in the repository from vector geometry.
