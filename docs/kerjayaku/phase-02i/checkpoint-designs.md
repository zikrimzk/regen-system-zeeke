# Checkpoint designs

Each article in `php/views/landing.html` links to a named illustration from `public/img/kerjayaku-world.svg` and receives a reversible active state from `public/js/mochi-story.js`.

| Scene | Illustration and purpose | Existing action |
| --- | --- | --- |
| Entrance | Kuala Lumpur skyline, miniature rail line and the start of the road | Start an account or follow the first marker |
| Welcome | Entrance arch and planted roadside | Sign in or register |
| Direction | Paired signposts | Pick a local demonstration choice |
| Resume Studio | Perspective desk, document and monitor | Start through registration |
| Templates | Studio display with multiple papers | Browse published designs |
| Milestone | Draft with approval mark and brief sparkles | Read the draft again |
| Packages | Toll lanes, illuminated gantry, booth and striped barrier | Compare real packages |
| Cover Letter Studio | Letter, desk and sealed envelope | Open the existing cover-letter route |
| Role fit | Papers and magnifier | Read job requirements and find real evidence |
| Tracking | Penang-inspired bridge | Note applications and follow-ups |
| Interview | Two chairs and a dialogue shape | Practise answering out loud |
| Day one | Entrance and a dressed Mochi | Register for the current workspace |

The role-fit, tracking and interview chapters offer career advice. They make no claims about currently available product features. The final scene depicts a fictional Mochi milestone.
