# Packages and templates

`/pricing` keeps `PublicSite`, `TokenStore` and `ReGenCommerce` as the sources for published package names, benefits, durations, regional prices and actions. `/packages` leads to the same page. The toll checkpoint now links directly to the pricing page. The mobile carousel snaps to cards, offers previous, next and numbered controls, and respects reduced-motion settings. It never advances automatically.

`/resume-templates` uses the visible results from `TemplateManagement::catalogue()`. Filters use the catalogued basic and premium tiers. The preview and PDF links open existing fictional public samples, and the authenticated `/templates` route keeps its existing role.

Both pages link back to their checkpoint. Browser back also retains the native history position. Package purchase authorization and candidate document policies remain with the original routes.
