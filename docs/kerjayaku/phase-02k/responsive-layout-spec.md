# Responsive layout

| Width | Landing | Authentication |
|---|---|---|
| 320–365 px | Compact brand, language, sign-in and appearance. Registration CTA starts in the hero. Product intro stacks above a phone-and-Mochi scene. | Form and guide stack. Registration field pairs become single-column. |
| 366–700 px | Device preview opens in Mobile mode. Career tool panels occupy roughly 86% of the rail with native snap scrolling. | A small Mochi guide precedes the visible form. Email and password inputs use 16px type. |
| 701–900 px | Desktop workspace and phone frame return. Hero copy and collage share the row. | Authentication uses one column through 760px; above that the form and screenshot guide share a row. |
| 901–1440 px | Wide asymmetric hero, alternating Studio placement and multiple visible tool panels. | Form remains the primary pane and the guide sits alongside. |

Gutters scale from 16 to 48px, content stops at 1,250px, and section gaps follow content. The device switches preserve intrinsic screenshot ratios. Focal areas and labels stay legible when a user selects the appropriate preview size. Controls use 44px or larger hit areas in the landing demo and navigation. Forms preserve browser autofill attributes and use the existing visual viewport handling. Preserve prior public fragment links such as `#ch1`, `#ch2`, `#ch3`, `#ch4`, `#studio` and `#faq-title`.
