# Phase 02K visual direction

Kerjayaku’s application is the hero. A restrained desktop frame shows the real candidate workspace. A real Cover Letter Studio phone capture complements it below or alongside, and Mochi introduces the tools with short dialogue.

The page proceeds through writing guidance, two Studios, a swipeable tool collection, a four-stage career journey, a package invitation, FAQ and the closing CTA. Existing template and package catalogue screens retain their dedicated flows.

Warm paper, charcoal, #B4233A and restrained gold form the public palette. Dark mode uses #17171B and neutral surfaces. Green is reserved for the existing Mochi character and semantic statuses. The same wordmark, native controls and Inter family appear in public and candidate entry views. The mobile entry variant places a small Mochi above the form and retains the form-first document order.

Illustration is limited to Mochi and real screenshot framing. The tool examples use simple inline UI fragments to explain one action at a time. All copy comes from the bilingual catalogue or a verified package setting.

The Adobe pages informed the use of product demonstrations and succinct CTAs. Hostinger informed the grouping of a broader catalogue and left/right discovery controls. Kerjayaku uses its own layout, code and imagery. [Adobe](https://www.adobe.com/), [Adobe Express resume page](https://www.adobe.com/express/create/resume), [Hostinger](https://www.hostinger.com/).
