# Motion and interactions

- Hero frames enter once with short translated fades. Mochi uses the existing sprite with one gentle wave. The composition is usable immediately and remains static under reduced motion.
- The writing showcase follows the tab pattern with Left, Right, Home and End keys, roving focus and one visible panel. Fictional prompt, answer and suggestion fade in sequentially. Replay restarts the local example. IntersectionObserver pauses unfinished motion outside the viewport and reduced motion shows all text at once.
- Each Studio selector uses two toggle buttons with pressed state. Responsive defaults apply until the visitor makes a selection. A specific selection survives resize for the current page.
- The career rail uses native overflow, scroll snap, previous and next controls and a continuous position indicator. Touch is handled by the browser. The compact career journey is a static list.
- Mochi responds to focus, limited non-password typing and existing form results. Credential denial uses the real 401 response. The UI submits and navigates immediately through the existing authentication logic.
- Package and template links use their real destinations. FAQ uses native disclosure elements. Appearance and optional storage reuse existing site controls.
