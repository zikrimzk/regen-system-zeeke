# Reusable handset and Studio captures

`PublicProduct::screenshots()` assembles the handset for the landing hero and both Studio switches. CSS separates the outer shell, glass and decorative hardware strip. The strip is above the screen and contains no simulated time, battery or status indicators. Each image preserves its native 390:844 ratio across modes. The outside silhouette is approximately 9:19.5.

The four source PNGs are real signed-in Chromium captures at a 390 × 844 CSS viewport and device scale factor 2. The disposable Amina fixture uses a fictional resume and cover letter. English and Bahasa Melayu were loaded separately. Desktop retains the verified current Studio captures from 02K.

| Asset | Purpose |
|---|---|
| `resume-mobile-{en,ms}.webp` and `letter-mobile-{en,ms}.webp` | 390 × 844 images for lower density |
| `resume-mobile-2x-{en,ms}.webp` and `letter-mobile-2x-{en,ms}.webp` | 780 × 1688 images selected by browser density or opened as the full-size preview |
| `source-resume-mobile-{en,ms}.png` and `source-letter-mobile-{en,ms}.png` | Browser source evidence beneath the 02M screenshot folder |

The protected application retains its own localization. A few pre-existing English field labels appear inside the real Malay Studio capture. The public surrounding UI and alt text use the selected language.
