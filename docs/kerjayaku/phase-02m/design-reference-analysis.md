# Phase 02M reference analysis

The four attachment images are evidence about proportion and organization. All production visuals use Kerjayaku's own UI and assets.

| Reference | What to carry forward |
|---|---|
| Two realistic handsets | A small rim, separate hardware safe area, useful screen scale and app imagery that preserves the viewport proportions |
| Career grid | Consistent icon weight, equal card columns where there is room, restrained surfaces and short descriptions |
| Corporate footer | Company identity first, named link groups, real destinations, and a clear copyright line |
| ReGen 1.0 | A stable header, shared container width, understated section breaks, and clear account and pricing destinations |

The old landing in Git at `c75b23c` used a shared `site-container`, real public package entries and a concise publisher footer. The attachment confirms that structure and its registration number. The 02L mobile evidence shows the clipped hero handset, a bordered-image Studio treatment, the sideways career rail and one Packages CTA without plan information. Phase 02M retains the current site hierarchy, neutral red/gold identity and real Studio pixels while revising those components.

The handset reserves top space above the app UI and preserves image proportions. Package controls use manual movement with keyboard navigation and position feedback.
