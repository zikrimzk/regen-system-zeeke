# Mobile-first layout

The browser gate starts at 390 CSS px, then repeats reflow on 360 and 320 CSS px before testing larger widths. The public pages use Inter, shared warm-neutral and charcoal tones, and the same Kerjayaku wordmark, red CTA and focus treatment. Public containers use a 16px minimum gutter and respect landscape cutout insets.

- At phone widths the hero places the headline and account CTA above one complete handset and the Mochi guide. The phone can extend below the first viewport in normal page flow.
- Studio marketing panels stack copy, the two device tab buttons and the frame. The browser or handset sets the height. The full-size link opens the real capture when a visitor wants more detail.
- The feature grid starts at one column, grows to two at 620px and three at 980px. The mobile package carousel keeps a partial next-card cue through 760px.
- The footer places business identity first and splits the links into two readable groups. Desktop aligns all three groups side by side.
- Authentication remains one column at mobile widths with the small existing Mochi greeting. Gutter and link changes use the same shared public component styles.
