# Career tools grid

Six cards show small related line icons, a tool name and one sentence. Mochi opens the real guidance example and Resume Review opens the existing dashboard flow. JD Matching, Application Tracker, Interview Preparation and Career Profile are visibly labelled as concept previews where their advertised workflows do not exist. No new features or entitlement rules were added.

The DOM order is the reading order. Meaningful links use normal keyboard focus and hover styles. Legacy anchors for tailoring and job discovery point to the relevant job-fit section. The 02L horizontal feature rail and its script were removed; the Packages carousel remains separately navigable.
