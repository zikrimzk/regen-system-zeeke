# Motion consistency

The commercial layer centralizes 140ms feedback, 190ms small transitions, 340ms entrances, 340ms device switches, and a shared ease-out curve. The hero frames settle once. Mochi retains its short existing expressive motion. The public example timeline keeps its deliberate reading pauses and locally generated review steps. Product tabs use a measured stage-height transition to avoid a permanent oversized stage.

Features use restrained color feedback. Pricing scrolls only after a finger gesture, explicit navigation or keyboard selection. Reduced motion uses static examples and instantaneous selection. Authentication never uses password contents to drive Mochi.
