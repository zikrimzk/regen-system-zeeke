# Kerjaya. · Concept comparison

Both options use the same fictional account with a resume in progress and a saved cover letter. The comparison isolates composition, navigation and editing rather than using different tasks or inflated claims.

| Surface | A · City to Career | B · Career Workspace |
| --- | --- | --- |
| Public landing | The forest lead, warm type and Kuala Lumpur artwork establish local identity. The familiar paper composition shows what Kerjaya. helps create. | The landing shows a miniature workspace and an actual route into the sample. The editing task is visible before sign-in. |
| Candidate workspace | A distinct left rail anchors navigation on desktop. A dark resume panel makes the active document the first task. | Top navigation gives more width to documents. The resume, next action and saved letter sit on quieter surfaces. |
| Resume Studio | A warm outline and preview area make the editor feel like part of the editorial brand. Phones open preview in a native dialog. | The neutral field and document layout keeps attention on the work. Phones use an explicit Write/Preview mode switch, while a single section picker stays available. |
| Main strength | The most distinctive Malaysian storytelling and strongest connection between public brand and signed-in experience. | The most direct path from the dashboard to editing and the clearest phone division between writing and checking the document. |
| Trade-off | Large illustrative assets and the dark panels put more emphasis on presentation. Closing a phone preview adds a transition, although the editor remains available beneath it. | Less immediate local character without the skyline. Product imagery and Malaysia-specific language have to carry that identity. The phone preview mode must preserve input and focus in production. |
| Implementation concern | Keep the skyline responsive, and retain all affordances at intermediate widths. The editor dialog must continue to work with the real PDF engine and mobile keyboard. | Confirm stable tab navigation, back behavior and preview cancellation. Retain real entitlements on production preview/export and keep the current account data model. |

## Recommendation

Select **Career Workspace** if the priority is a consistent product from the first visit to repeated editing. Its strongest advantage is the named, reversible mobile preview mode and the same task vocabulary in landing, dashboard and editor. Choose **City to Career** if local editorial identity is the deciding factor. Its landing is more distinctive, and the native dialog is familiar, with slightly more friction for repeated preview checks.
